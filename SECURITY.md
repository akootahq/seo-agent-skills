# Security

Please report a vulnerability privately, never in a public issue:

- through GitHub: **Security → Report a vulnerability** on this repository, or
- by email to rakesh@agentnumber10.com.

Include the skill, the agent you ran it in, what an attacker could do, and the
steps to reproduce it. You will get a reply within three working days, and a
fix is released as soon as it is ready. Reporters are credited in the release
notes unless they prefer not to be.

Only the latest release is supported.
